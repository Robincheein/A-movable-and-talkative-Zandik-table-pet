# 步态与落地修正：2.0.0-animal.2

## 原因及修正

上一套四帧是分别绘制的姿势：视角、脚掌落点、头身位置不同。原图按整个外轮廓最低点对齐，坐姿尾巴低于脚，因此脚掌悬空。原引擎还保留 `-2 / -4 / -8` 像素每帧的不同速度与最快 80ms 的图片切换。

本版通过内置 imagegen 重画一张站立 + 八帧步态图集，并重画脚掌贴地的坐姿。继续使用已获用户同意的本地抠图与统一尺寸处理。原始图及生成提示词均保存在 `assets/concepts/dottore_walk_v2/`。

- 站立与行走共享图集比例；统一缩放，不单独拉伸每张图。
- 八张步态按顺序播放，每帧 4 个时钟步，即 160ms；完整循环 1.28 秒。
- 所有走路/跑步/携带窗口移动动画都使用 `-1,0`，约每秒 25 逻辑像素。普通走路原为每秒 50，跑步 100，冲刺 200。
- 支撑脚对齐 `y=128`，站姿和行走不再按尾巴落点定位；坐姿也单独检查脚掌高度。
- 自动快跑、快速扭头、抖脚、趴着滑行频率改为 0，保留定义方便恢复。未启用任何爬墙入口。
- `img` 与 `dist/img`、两份 XML 配置均已同步。最初步态更新仅涉及美术与配置；下方的交互补丁还需要重新构建并安装 JAR。

## 检查及效果

- `tests/test_walk_assets.py`：支撑脚接触基准、共同缩放、八帧不同、两份资源一致，通过。
- 更新后的 `AnimalSkinSelfTest`：56 张运行图片、引擎 XML 校验、左右边缘落地、32 个时钟步速度/高度恒定、八帧全部播放、禁用快动作、拖拽阈值，通过。
- 测试使用已经安装的 `dist/Shimeji.jar`，不调用真实模型。
- 循环预览：`assets/skins/dottore_fox/walk_v2/walk_preview.gif`。绿色细线标记落地基准；放大预览不等同于桌面实际显示尺寸。

原画之间仍可能存在细微形变，不能仅凭自动测试保证主观观感完全自然；本版没有用半透明叠帧制造重影。建议实际看一遍步态后再决定是否继续精修。

## 使用及回退

从托盘退出正在运行的桌宠，再用根目录启动 BAT 打开即可加载新图和配置。没有结束用户正在运行的进程。

本次修改前资源及程序在 `backups/animal1-before-walk-v2/`，不上传私人备份。此前动物版仍在 Git 标签 `v2.0.0-animal.1`。本次修正尚未提交或推送 GitHub。

重新导出：`conda run -n steel python tools/prepare_walk_v2.py`，然后运行 `tools/configure_animal_skin.ps1`。从旧入口 `prepare_animal_sprites.py` 重建时也会自动应用新步态，避免回到旧四帧图。

- 拖拽不再重置计时或强制转向，不再套用固定的鼠标下方 120 像素偏移。保留抓取位置，240ms 轻微提起，随后使用原拖拽图的运行时小角度摇晃；不是新绘制的逐肢体动画。不按超时随机挣脱，也不在边缘自动传送。
- 落地 primitive 原误用了 shime18/19（现在是睡姿）。改为新站姿，320ms 脚底固定的轻微压缩回弹，然后站稳；真正的睡觉行为不受影响。
- 对话框按不透明像素范围定位，留 6 像素间距；顶部放不下时改放下方，并限制在显示器工作区内。
- `tools/build_animal.ps1` 编译 Java 8、测试源码和候选 JAR，通过全部检查后才将候选包放入自动安装位置。使用根目录启动 BAT 会安装待更新包，须先从托盘完全退出旧桌宠。
- 新增离线回归覆盖实际长时间拖拽、边缘控制、释放落地链、缓冲帧、对话框位置，以及模拟 API 的思考过滤、中文纠偏和工具动作保留。未使用私人密钥调用真实模型；视觉观感仍需要桌面试用确认。

### 拖拽偶发闪跳补丁

摇晃回到零度时，旧 `motionFrame` 直接返回原始 128 像素图，非零度则使用带留白的 160 像素图，中心也从 (64,128) 变成 (80,144)。虽然最终坐标能对齐，但旧渲染流程先移动窗口、再异步换图，可能短暂把旧图画在新坐标上。该画布/中心不一致已由回归测试在修正前复现。

零度帧现也使用相同留白，拖拽过程中所有角度共用画布和中心；保留提起过渡与轻微摇晃。Windows 渲染改为在界面线程用一次 UpdateLayeredWindow 提交图像与目标位置，再同步 AWT 坐标；刷新队列仅保留最新完整帧，防止旧鼠标坐标积压。不更改走路速度、人物图、API 或记忆。

检查包括 0.75/1/1.5/2 倍尺寸下 -6 到 +6 度的中心和画布一致性，以及真实刷新队列的界面线程执行、连续 100 次更新合并、图像/坐标配对、退出后不再显示。队列测试替换最终绘制步骤，不弹出桌宠；桌面实际观感仍需重启试用确认。
