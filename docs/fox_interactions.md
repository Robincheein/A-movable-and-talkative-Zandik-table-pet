# 狐狸摸头互动

右键桌宠 →「摸摸头」。仅在站稳时可开始；左键单击仍打开聊天，拖拽随时打断。逗狐狸和喂食已移除，原有走路、拖拽、着地素材保留。

## 动画

采用新画的手与狐狸一体图片，不在运行时绘制悬空手掌。补帧版新增七张，总计十二张独立素材（含配套静坐），不以重复文件冒充新画帧。每次单次播放，结束后恢复正常行为：

- 普通拒绝：12 个阶段、8 张不同图片，约 1.84 秒；含抬爪半程、开始拨手、落爪。
- 烦躁拒绝：14 个阶段、9 张不同图片，约 1.84 秒；不先播放接受触摸。
- 短暂接受：15 个阶段、7 张不同图片，约 2.04 秒；手掌小幅左右轻抚，再收回。

引擎仍按每秒 25 次更新运行，动作移动主要保持 2～4 次更新（80～160 毫秒），强调姿势最多 6 次更新（240 毫秒）。画帧数量不等于引擎刷新率；轻抚和回落会合理复用姿势，但不在几张关键图之间无限循环。

所有图片统一为 128×128 透明画布，定位点 (64,128)。按躯干下方地面爪子对齐，不按大尾巴边界对齐；一段动画内锁定朝向，角色位置不移动。源码原图保留，运行资源位于 img/fox_pet_*.png 与 dist/img/fox_pet_*.png。

这是补有中间姿势的短动画，并非每秒 25 张独立原画。比第一版增加了抬爪、拨手、落爪和轻抚细节，若需要更高帧率的细腻运动，后续仍可进一步补帧或分层绑定。预览脚本直接读取 Java 的实际播放序列，避免演示与程序使用不同节奏。

## 本地摸头耐心

每只桌宠拥有独立的内存状态，不调用 API，不修改对话和长期记忆；新进程从 60 开始。右键菜单显示当前「摸头耐心」。

| 耐心 | 拨开手 | 生气挡开 | 短暂接受 |
| --- | --- | --- | --- |
| 低于 35，烦躁 | 25% | 75% | 0% |
| 35～不足 65，平静 | 80% | 15% | 5% |
| 至少 65，不错 | 50% | 5% | 45% |

每次按触摸前的状态抽取一次反应，随后耐心减少 18。距上次触摸不足 20 秒，再减少 10；最低 0。随时间每 10 秒恢复 1，最高 75。查看菜单不会额外增加恢复量。重复触发或打断后再摸也会计入，不会通过反复点击刷出接受。

此状态只是桌宠对摸头的容忍度，不冒充大模型推断的真实心情。不把操作者当作潘塔罗涅，也不引入冒充身份的特殊权限。

## 维护与验证

- 原图及内置 imagegen 提示词：assets/concepts/dottore_pet_moods_v2/ 和 assets/concepts/dottore_pet_moods_v3/README.md。
- 透明素材、定位信息、检查图：assets/skins/dottore_fox/pet_moods/。
- 资源处理：conda run -n steel python tools/prepare_pet_sprites.py。
- 动图预览：conda run -n steel python tools/preview_pet_animation.py；输出 assets/skins/dottore_fox/pet_moods/animation_preview.gif。
- 互动实现：src/com/group_finity/mascot/action/FoxInteraction.java。
- 耐心逻辑：src/com/group_finity/mascot/PetMood.java。
- 构建与回归：powershell -NoProfile -ExecutionPolicy Bypass -File tools/build_animal.ps1。

离线测试覆盖三种反应与双向图片、地面定位、单次结束、拖拽打断、悬空禁止、概率分布、连续触摸扣分、恢复上限及多桌宠隔离。同时运行原走路、拖拽、落地、窗口帧更新、角色提示词回归。没有调用真实模型或自动打开可见桌宠，实际交互观感仍需重启后体验。

构建产物为 dist/Shimeji.jar；安装受限或文件被占用时保留 dist/.updates/Shimeji.jar，原启动 BAT 会在下次启动前安装。不强制终止正在运行的桌宠。
