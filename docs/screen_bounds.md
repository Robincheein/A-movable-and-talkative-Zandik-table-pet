# 屏幕边缘控制

默认启用，不需要另开开关。使用引擎当前屏幕工作区（主屏排除任务栏），按角色缩放后的可见图像计算边界，透明画布不占边界距离。

- 走路遇到左右边缘：限制在可见范围内，结束当前移动动作并朝内转向，随后回到普通行为选择。
- 拖拽：四边都受约束；不会自动松手、切换为下落或随机传送。鼠标返回可用范围后继续跟随，松开才结束拖拽。
- 下落、摸头、图片切换及调整人物大小：显示前再次限制边界，避免尾巴、耳朵或互动手掌越界。
- 保留脚底定位点不低于地面，避免因为图片下方透明留白而陷入任务栏。
- 关闭爬墙的设定不变，单击聊天与 8 像素拖拽阈值不变。

实现：ScreenBounds.java 为纯几何计算；Mascot 在行为更新后和显示前执行约束；Move 在受限时结束移动。UserBehavior 不再执行屏外随机传送。负坐标工作区受几何测试覆盖，多屏区域选择仍使用原引擎，不改变其显示器切换规则。若人物大于整个工作区则只能居中溢出，数学上无法完整容纳。

验证：ScreenBoundsSelfTest 覆盖四边、负坐标、多种缩放与重复约束稳定性；AnimalSkinSelfTest 使用真实图片测试四角越界拖拽、返回、释放和不可达走路目标，并继续执行原有步态、落地、摸头与窗口回归。

本地旧桌宠占用 dist/Shimeji.jar 时，新版暂存在 dist/.updates/Shimeji.jar。退出托盘中的整个程序，再运行根目录「启动多托雷.bat」自动安装。GitHub 的 dist/Shimeji.jar 应始终采用通过测试的 build/animal_candidate.jar，而不是被占用的本地旧文件。
