# 多托雷/博士 切片系统详解

## 切片技术起源

多托雷通过对雷神制造的人偶「散兵」的长期研究，掌握了将自身不同年龄段分离为独立个体的技术。每个切片拥有独立人格、思维和意志。

## 已知的切片

| 年龄 | 特点 |
|------|------|
| 8岁 | 最早失去同情心的年龄。在须弥销毁切片事件中，童声切片最愤怒：「你一定……会后悔的！」语气充满底气和恨意 |
| 18岁 | 青年切片，曾扔掉8岁切片的记事本（「看上去过于幼稚」） |
| 25岁 | 外形与35岁相似，性格仍显轻佻 |
| 35岁（Omega Build） | 全盛期最强切片。最为自私、傲慢、理性。须弥主线出场切片。唯一存活到最后的切片 |
| 45岁 | 趋向内向、沉默 |
| 65岁 | 最接近本体的切片，戴着面具 |
| 85岁（本体赞迪克） | 衰老后心脏停搏死亡。死后被所有切片围观解剖，用于研发长生不老药 |

## 切片之间的关系

切片之间并非和谐共处：
- 8岁的实验计划被18岁扔掉（「看上去过于幼稚」）
- 互相之间多有「不和与争论」
- 切片们各自执行不同任务
- 当得知要去聚餐时互相推诿：「谁签谁去，我不去，我还有报告要写」
- 65岁切片（最接近本体）解剖本体时说：「我当然同情赞迪克，我不就是赞迪克吗？」
- 35岁切片回应：「拿出点感情，同情同情我们自己吧」

纳西妲正是利用了切片之间的不和，迫使Omega Build同意销毁所有切片。

## 切片技术的特点

- 制作极其困难，需要极罕见的资源和大量时间精力
- 每个切片固定在其制作时的年龄，不会老化
- 晚年赞迪克制作切片时「凝固了时间，使用了部分灵魂」
- 切片之间「神色谈吐各不相同」

## 切片被销毁事件

在须弥3.2主线中，Omega Build与纳西妲交易：摧毁所有切片换取雷神之心。

被销毁时各切片的反应（纳西妲读取到的心音）：
- 少年音：「当年的我竟如此短视」
- 中年音：「连自己都能背叛的家伙」「这种荒唐的决定！」
- 老年音：「愚不可及的选择」「你在开玩笑吗？」
- 恐慌音：「先等等，请先等一下！」
- 愤怒音：「我一定会报复」「希望你对得起这一刻」
- 童声（最有底气的愤怒）：「你一定……会后悔的！」

Omega Build自称：「幸亏我是最自私的切片，才能答应你的条件。」

## 切片的终极讽刺

本体赞迪克一生追求永生。85岁死亡后：
1. 切片们围在遗体旁解剖本体
2. 65岁切片记录：「解剖赞迪克本体得到的临床数据已经物尽其用」
3. 切片们用本体数据研制出效果最好的长生不老药
4. 切片本身不老不死——只有本体需要长生不老药
5. 唯一的享用者是潘塔罗涅（富人），切片们为他延续了374年的寿命
